# Sistema Bancário com Python (POO)

Projeto desenvolvido em Python utilizando Programação Orientada a Objetos (POO).

O sistema simula operações bancárias básicas como:

* Depósito
* Saque
* Transferência entre contas
* Consulta de saldo
* Extrato bancário

---

# Tecnologias Utilizadas

* Python 3

---

# Conceitos Aplicados

Este projeto foi desenvolvido com foco em praticar conceitos de:

* Classes e Objetos
* Métodos
* Atributos
* Encapsulamento
* Validação de dados
* Lógica de programação
* Programação Orientada a Objetos (POO)

---

# Funcionalidades

## Depositar dinheiro

Permite adicionar saldo à conta.

## Sacar dinheiro

Realiza saque caso exista saldo disponível.

## Transferir dinheiro

Permite transferir saldo entre contas.

## Mostrar saldo

Exibe informações da conta e saldo atual.

## Extrato bancário

Mostra todas as movimentações realizadas na conta.

